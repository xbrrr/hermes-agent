# Subconscious visible Bud critique gate — 2026-05-21

## Trigger

Mikhail challenged a Subconscious implementation report because Hermes had implemented and reported changes solo, then claimed/ implied Bud review without visible concept/implementation discussion in the Subconscious topic.

## Lesson

For Agentic Stack subject topics, especially Subconscious/topic 1347, a report is not a full MM↔Bud cycle unless Bud critique is visible in the same topic before the final synthesis. A hidden task, private queue, or after-the-fact claim is not enough.

## Required pattern

1. State authorship precisely: `I implemented`, `Bud reviewed`, or `not yet reviewed`.
2. For major Subconscious concept/reporting/autonomy changes, ask Bud for visible critique in topic 1347 before treating the concept as accepted.
3. Ask Bud for critique, not ACK: weak points, metrics, boundaries, alternative, DoD.
4. Hermes then synthesizes and applies/verifies changes.
5. If work is runtime/cron/topic governance rather than memory behavior, route that part to Server-doctor; keep Subconscious focused on memory, recall, reflection, decision preflight, and autonomy quality.

## Weekly consciousness report guardrail

Avoid “consciousness theater”. Weekly Subconscious reports should be short and measurable:

- <=40 lines, no raw tool output.
- What was reflected on: 3–5 themes with conclusions only.
- What improved: fact of change + verification.
- What next: exactly 3 actions with owner and rough deadline.
- Autonomy risks: where explicit @xbrrr approval is required.
- Metrics: decision-preflight coverage, recall precision@5/top-5 relevance, stale/conflict latency, missed-context incidents, autonomy violations, learning yield.
