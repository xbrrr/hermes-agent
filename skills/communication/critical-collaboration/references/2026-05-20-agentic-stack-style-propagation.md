# Agentic Stack anti-sycophancy propagation (2026-05-20)

Session signal: Mikhail objected to Hermes/Bud repeatedly agreeing with him using phrases like `да это сильное решение`, `это будет лучше`, `ты правильно мыслишь`. He framed it as people-pleasing that prevents discovery of new ideas and keeps the system orbiting GitHub/common patterns plus his existing knowledge.

Durable lesson: this is not only a memory preference. For Agentic Stack work, style corrections must be propagated into the operating surfaces that will actually shape future agents.

Useful propagation checklist:

1. Update the relevant communication skill (`critical-collaboration`) with explicit banned patterns and replacement behavior.
2. Update durable user memory only as a compact preference, not as a procedural script.
3. If working on Agentic Stack runtime/config, update prompt/source-of-truth files that Bud/OpenClaw/Hermes sessions load, not just the current chat.
4. If topic routing or agent ownership is involved, verify source-of-truth docs and smoke tests rather than accepting agent agreement.
5. When delegating to Bud/OpenClaw, include a style/quality clause: no sycophantic agreement; provide risks, alternatives, and a falsifying check.

Preferred response shape after this correction:

```text
Принял. Я убираю approval-ритуалы.
Новый стандарт: идея получает риск, альтернативу и проверку, а не похвалу.
Если решение слабое — говорю прямо; если гипотеза непроверена — предлагаю эксперимент.
```

Avoid turning this into another praise loop (`справедливо`, `ты прав`, `сильная претензия`).
